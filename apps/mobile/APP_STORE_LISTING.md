## דברים שעדיין חסרים לפני הגשה בפועל
1. **Team ID + ascAppId** — ממתינים לאישור ה-Apple Developer Program (Pending)
2. **צילומי מסך** — iPhone 6.7" ו-5.5" (אין צורך ב-iPad, `supportsTablet: false`). אפשר להפיק רק אחרי `eas build` תקין
3. **חשבון בדיקה קבוע** לבודק של אפל (ראו סעיף למעלה)
4. עדכון `eas.json` → `submit.production.ios.ascAppId` ו-`appleTeamId` בערכים האמיתיים
